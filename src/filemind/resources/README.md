# BGE WordPiece vocabulary

`bge-vocab.txt` is the unchanged vocabulary of [BAAI/bge-small-zh-v1.5](https://huggingface.co/BAAI/bge-small-zh-v1.5/tree/7999e1d3359715c523056ef9478215996d62a620), released under MIT. The model's tokenizer configuration specifies case-sensitive WordPiece and Chinese character splitting. See [BGE-LICENSE.txt](BGE-LICENSE.txt) for the upstream license.

The vocabulary makes tokenizer-based chunking available offline. The ONNX weights are installed separately into the local application data directory.
