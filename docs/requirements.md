# 需求与验收

FileMind 面向大学生和个人用户，以 Windows 桌面应用管理本机资料。用户可按内容找文件、定位原文、基于材料问答，并审核整理方案。设计规模约为 1000 份文件和数万文本块，性能由评测确认。首版范围包括 P0 和精简 P1。

## 框架阶段

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| 基础-01 | Windows 桌面窗口 | 在 Windows x64 上可启动，四个导航页面可切换并显示各自详情 |
| 基础-02 | 本地存储 | 首次启动创建数据库和受管工作区，显示结构版本与 FTS5 状态，重新打开后恢复上次页面 |
| 基础-03 | 工程可复现 | 从依赖锁文件安装，可运行检查、测试和打包。需求、架构、开发进度和变更日志可从仓库找到 |

## P0 文件库、检索与问答

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| P0-01 | 导入与关联 | 接入 PDF、DOCX、PPTX、MD、TXT。导入保留同名副本，关联目录在白名单内只读。显示索引状态和失败原因 |
| P0-02 | 解析、来源与更新 | 保存未分词原文及页、幻灯片、段落或行号。长段落按实际 tokenizer 切块。任务可重试，文件修改和删除后索引一致，无文本 PDF 标记需要 OCR |
| P0-03 | 智能检索 | 支持关键词、语义和混合检索、按文件聚合和统一过滤。测试特殊术语、原文定位和无模型时的关键词降级 |
| P0-04 | 问答与引用 | 支持全库和限定文件范围，应用服务校验引用 ID、版本与摘录。LLM 默认关闭，服务失败时显示带来源的摘录 |
| P0-05 | 检索评测 | 用至少 25 份样例和 30 条查询实测文件级 Hit@5、MRR 和延迟，单列无答案问题及跳过的模型测试 |

## P1 文件整理

| 编号 | 需求 | 验收条件 |
| --- | --- | --- |
| P1-01 | 标签与完全重复文件 | 可编辑标签、核对模型或规则建议，SHA-256 相同的文件显示各自位置 |
| P1-02 | 预览、确认、执行和撤销 | 预览时只生成计划。确认时校验摘要和文件状态，逐项记录结果，支持重启后查看和按逆序安全撤销 |
| P1-03 | 桌面验收流程 | 从导入样例出发，完成索引、检索、打开原文引用、整理确认和撤销，保存实际验证结果 |

## 数据与功能边界

- 文件与目录须经用户明确接入。导入只写入受管工作区，移动仅限受管文件。重名、越界、链接绕过、内容变更和撤销冲突有明确处理。扫描不完整时保留未确认删除的记录。
- 文件原文、密钥和模型权重保存在本地。远程问答须显式启用，并仅传输必要查询和证据。文档内容只作为数据，问答与模型输出无权发起文件操作。
- 后续评估 OCR、近似重复检测和重排序。多人协作、云盘同步、全盘扫描和自动删除超出项目范围。
