# P0 检索评测

样例库含 25 份合成资料，PDF、DOCX、PPTX、MD、TXT 各 5 份。37 条查询中，32 条有预先标注的目标文件，5 条在样例中无答案。样例文本与标注保存在 [corpus.json](../samples/corpus.json)。脚本每次在临时资料库生成实际文件并重新导入。

Windows 11 x64（26200）、Intel Core i9-14900HX、Python 3.12.13、SQLite 3.53.1。语义和混合使用本机的 [BAAI BGE Small 中文模型](https://huggingface.co/BAAI/bge-small-zh-v1.5) 的 [固定版本 ONNX 转换](https://huggingface.co/Xenova/bge-small-zh-v1.5/tree/75c43b069aac4d136ba6bc1122f995fedcfd2781/onnx)。

| 模式 | 基线 `6c0bd43` Hit@5 | `8ce074e` Hit@5 | `8ce074e` MRR | 预热后 p50 | 预热后 p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 关键词 | 30/32 | 29/32 | 0.906 | 29.2 ms | 37.7 ms |
| 语义 | 31/32 | 27/32 | 0.828 | 52.5 ms | 66.7 ms |
| 混合 | 31/32 | 31/32 | 0.953 | 67.2 ms | 79.0 ms |

MRR 使用每条有答案查询的首个正确文件排名，漏检按零计。延迟在每种模式预热一次后记录 37 条查询，包含检索、文件状态检查与结果读取。25 份文件导入和文本索引耗时约 9.17 秒。语义首次查询（加载权重并生成全部向量）约 1.91 秒，混合复用了已生成的向量。去掉 0.53 的余弦门槛后，合成语义 Hit@5 为 30/32，但全部 5 条无答案查询都有结果。

## 复现

```powershell
. .\scripts\dev-env.ps1
uv run --locked python -m filemind --install-model --data-dir .\data\p0
uv run --locked python -m samples.evaluate --model .\data\p0\models\bge-small-zh-v1.5.onnx --output .\data\p0\evaluation.json
```

JSON 报告记录每条查询的前五结果、目标排名和无答案候选数。缺少模型时报告跳过语义与混合测量。此次实测运行了三种模式。远程问答使用本地模拟接口验证，未调用第三方模型服务。

## 实盘回归 · 2026-11-14

使用本机资料库中的课程资料、讲义和表格建立 36 条有标注的查询，并加入 6 条预计无答案的查询。目标按 SHA-256 匹配，完全相同的副本均算命中。评测通过 `Search.find` 使用只读 SQLite 连接和已有 BGE 向量，预热后取前 10 个结果。标注与逐条报告保存在本机 `data/evaluation/`。

| 模式 | 基线 Hit@5 | 本轮 Hit@5 | 基线 MRR@10 | 本轮 MRR@10 | 基线 p95 | 本轮 p95 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 关键词 | 33/36 | 32/36 | 0.829 | 0.824 | 4.02 秒 | 2.73 秒 |
| 混合 | 33/36 | 34/36 | 0.730 | 0.802 | 26.63 秒 | 2.91 秒 |

最终复测开始时资料库有 12,843 条记录，后台扫描仍在运行。更早的固定快照复测混合 Hit@5 同为 34/36，p95 为 1.08 秒。本轮两种模式都对 5/6 条预计无答案的查询返回了结果。评测集来自一台机器，且用于本轮参数调整。复跑原有合成评测，混合 Hit@5 为 31/32，MRR 为 0.953，5 条无答案查询中 1 条有结果。纯语义 Hit@5 为 27/32，基线为 31/32。

## 关键词放宽与向量缓存复测 · 2026-11-14

实盘对照使用同一个只读 SQLite 快照，含 13,454 条文件记录。沿用 36 条有答案查询和 6 条预计无答案的查询，使用已有 BGE 向量，预热后取前 10 个结果。两次都按原路径检查文件状态。快照固定了索引内容，实际查询时延仍受磁盘缓存和后台负载影响。
